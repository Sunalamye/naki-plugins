# naki-plugin-ex-local-unlock

只在這台裝置上，改對局內自家的稱號與裝扮顯示。伺服器與其他玩家看到的仍是帳號實際擁有的外觀。授權 CC0-1.0。

> 本插件只改你這台裝置上看到的畫面，其他玩家看到的仍是你帳號實際擁有的外觀。改寫遊戲封包可能違反雀魂的服務條款，有被封號的風險。**只在測試帳號使用，不要在主帳號啟用。** 停用本插件後，請重新載入遊戲頁面，畫面才會完全恢復。安裝插件等於信任插件作者：插件與遊戲在同一個環境執行，Naki 無法阻止插件做其他事。

## 行為

- 只做 `authGame` 回應中自家那一筆玩家的稱號（field 3）與裝扮（field 10 的 `item_id`）。座位、其他玩家、機器人、帳號 id、暱稱、角色、皮膚、頭像都不動。
- 只等長就地改寫。新值與原值的 varint 位元組數不同、欄位不存在或結構不符時，該項不改，並在 Naki log 記一行。
- 不送出任何請求，不改任何送出封包。`onSend` 只讀 `authGame` 請求的 `account_id`。
- 自家身分取自登入回應，必須與 `authGame` 請求的 `account_id` 相同，否則不改寫。登出或被擠下線後重置身分。
- 未勾選「我確認只在測試帳號使用」或未啟用時，不做任何事。
- 插件不內建任何 id。稱號 id 與 `slot=itemId` 都由你在設定頁輸入。

## 使用

1. 在插件頁啟用，開啟設定頁，勾選確認、啟用，輸入稱號 id 與裝扮。
2. 重新載入遊戲頁面並重新登入。設定只在重新登入後的下一場對局生效；熱啟用時身分未知，不會改寫。
3. 需要 Naki 2.18.0 以上才看得到自帶設定頁；舊版 Naki 會忽略 `settingsUI`，改以 schema 自動渲染設定。

## 未驗證

欄位號取自已知過期的 `liqi.json`，尚未用 live 封包確認。實際 id 值的編碼長度是否可交付、`authGame` 回應是否被 Naki 的 `replace` 接受，都需在測試帳號 live 驗證。
